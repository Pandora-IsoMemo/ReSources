# Is Deepest Entry

Checks if names of the list are targetNames (deepest hierarchy in a
values object)

## Usage

``` r
isDeepestEntry(entryContent)
```

## Arguments

- entryContent:

  (list) element of values, e.g. values\$source, values\$sourceUncert,
  values\$sourceOffset, values\$sourceOffsetUncert
