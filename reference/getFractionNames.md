# Get Fraction Names

Get Fraction Names

## Usage

``` r
getFractionNames(
  withComponents,
  withConcentration,
  weights,
  concentration,
  targetNames
)
```

## Arguments

- withComponents:

  (logical) TRUE if "Include components"

- withConcentration:

  (logical) TRUE if "Include concentration"

- weights:

  (list) list of weights tables

- concentration:

  (list) list of concentration tables

- targetNames:

  (character) names of the targets
