# Check if data dimensions are correct

Check if data dimensions are correct

## Usage

``` r
checkDataDimensions(data, valueNames, modelOptions, argName = NULL)
```

## Arguments

- data:

  list: input data

- valueNames:

  list: contains names for the `targets`, `fractions`, and `sources`

- modelOptions:

  list: contains elements `burnin` and `iterations`

- argName:

  character: name of argument displayed in error message
