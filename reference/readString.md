# Read String

Read String

## Usage

``` r
readString(content, mode, withColnames = TRUE)
```

## Arguments

- content:

  (character) string from clipboard

- mode:

  (character) paste mode, one of "auto", "comma-separated",
  "tab-separated", "semicolon"

- withColnames:

  (logical) should the first row be used as colnames?
