# Server Function for the FRUITS Module / Tab

Server Function for the FRUITS Module / Tab

## Usage

``` r
fruitsTab(
  input,
  output,
  session,
  isoMemoData = function() {
     list(data = NULL, event = NULL)
 },
  isoDataExport = function() {
     list(data = NULL, event = NULL)
 }
)
```

## Arguments

- input:

  input

- output:

  output

- session:

  session

- isoMemoData:

  data from IsoMemo App

- isoDataExport:

  data to export to IsoMemo App
