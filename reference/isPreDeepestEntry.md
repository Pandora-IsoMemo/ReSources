# Is Pre Deepest Entry

Checks if names if the list are obsvnNames (hierarchy above targetNames
in a values object)

## Usage

``` r
isPreDeepestEntry(entryContent)
```

## Arguments

- entryContent:

  (list) element of values, e.g. values\$source, values\$sourceUncert,
  values\$sourceOffset, values\$sourceOffsetUncert
