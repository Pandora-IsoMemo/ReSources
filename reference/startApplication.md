# Start Application

Start Application

## Usage

``` r
startApplication(
  port = 4242,
  host = "127.0.0.1",
  launch.browser = getOption("shiny.launch.browser", interactive())
)
```

## Arguments

- port:

  port of web application

- host:

  accept connections from this address

- launch.browser:

  whether to launch the application in a web browser
