# Build object of class [`fruits`](https://pandora-isomemo.github.io/ReSources/reference/fruits.md) from shiny input

Build object of class
[`fruits`](https://pandora-isomemo.github.io/ReSources/reference/fruits.md)
from shiny input

## Usage

``` r
shinyInputToClass(values, priors, userEstimates)
```

## Arguments

- values:

  list: Shiny input

- priors:

  list: input\$priors

- userEstimates:

  list: input\$userEstimates
